    Find these scenes in ASF Vertex

    Both NISAR products are provisional (CRID P05023). Use the product IDs to find the original scenes in ASF Vertex.

    Steps to follow:

    1. In Vertex, switch the Search Type (top dropdown menu) from Geographic Search to List Search.
    2. Set the Dataset to NISAR.
    3. Paste the string directly into the text area box and click Search.

    Use the Copy ID button on a scene card to copy its ID, or Copy both IDs to put both scenes on separate lines, then paste into the text box in step 3. Vertex returns exactly those scenes, so you do not need to draw an area or pick dates.
